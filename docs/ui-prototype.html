844 × 390 · UI 固定像素

怎么用这份原型：切上面的「区域块尺寸」，会发现球场跟着变、控件一个像素都不变——这就是要落地的规范。 右侧 ⌄ 按钮展开功能坞；顶栏的「⌄ 收起」把顶栏藏起来只留右上角浮标；「尺寸标注：开」会在控件角上标出它的固定高度。 组件库页把当前所有按钮 / 面板 / 状态 / 弹窗都摆齐了。
尺寸 token：--ui-bar-h 44 --ui-btn-sm 36 --ui-btn-md 44 --ui-btn-lg 52 --ui-icon 34 --ui-chip-h 24 --ui-dock-w 200。可用性口径：Web 指针目标 ≥ 24px（WCAG 2.2 AA），相邻触控目标间距 ≥ 8px。
