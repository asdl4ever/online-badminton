# 羽毛球 · Badminton

浏览器里的 2D 侧视角羽毛球游戏，外加一整圈周边玩法：攀岩、潜水抓鱼、采矿场、**农场**、晋级赛馆、名人堂（含传奇 AI 皮泽恩）、**小黄龙联名**、**哥斯拉来袭** Boss 战、**外星人降临**。Vue 3 + TypeScript + Vite 前端，Phaser 4 渲染，支持单机（对战 AI / 发球机）、WebRTC 点对点联机，以及 **941 件**可收集的外观装扮（含 **165 款头饰**、**35 款坐骑**与荣誉/活动限定、**10 只《山海经》怪物皮肤**）。

- **物理**：羽毛球是**自己写的**（重力 + 二次空气阻力），不用 Phaser 内置物理——高速衰减必须靠二次阻力，而且联机需要确定性；采矿的碎石复用同一套积分器；潜水是水阻 + 8 向游动；攀爬模式则用 **Phaser 内置的 Matter**（需要真正的刚体和转轴约束）
- **玩法**：单机（对战 AI / 发球机连击里程碑）、联机对战（含乐趣模式）、攀爬挑战、海湾潜水（鱼王 / 闪光鱼 / 海底宝箱 / 每日任务）、采矿场、**农场采棉花**、理发店、**晋级赛馆**（杯赛 + 荣誉点）、**名人堂**（排行榜 + 挑战传奇 AI）、**小黄龙联名**（挑战 + 转盘）、**哥斯拉来袭**（拍火球打 Boss，杀掉后摇三选一战利品）、**外星人降临**（60 秒拍陨石）、商店（活动 / 宝箱 / **金币商店** / **荣誉柜台**）、宠物店
- **网战**：房主权威 + 客户端预测 + 快照推算 + 延迟补偿；潜水/采矿/大地图是「各玩各的」轻量位姿同步；好友与邀请走一条常驻的 `/lobby` 大厅通道（匿名，只转发在线与邀请，邀请带场景标签；**点邀请自动建房，无需先手动开房**）
- **传输**：PeerJS(WebRTC) 直连优先，打不通自动降级到自己服务器上的 WebSocket 中继
- **界面**：Soft UI Evolution 亮色主题，桌面 + 手机双端；对局页**没有顶栏**，只有左上角「退出 + 模式设置」和右上角一排图标，中间整块是游戏画面
- **外观**：角色形象 / 头饰 / 翅膀 / 披风 / 光环 / 地环 / 宠物 / 球拍皮肤 / 拖尾 / 挥拍拖尾 / **坐骑** / 命中特效，共 **723** 件；**宝箱（钥匙开）** + **🧩 碎片兑换（6 件专属）** + **荣誉商店** + **金币商店（含 10 款专属形象 + 10 款专属坐骑）** + 活动限定（发球机套装 / 哥斯拉来袭套装 / 外星人降临套装 / 宇宙龙域套装）
- **货币与材料**：采集类玩法（🌾 采棉花 / ⛏️ 砸矿 / 🤿 抓鱼）**给的是材料，不是金币**——棉花（一朵 1 个）/ 矿石（石头 1、铁矿 2、金矿 4、钻石 10）与鱼都进仓库，**全都要拉去赚钱区交给农场主收购**才变成金币（棉花 ¥5/朵、矿石 ¥8/个、鱼按条计价），商店买皮肤、升装备、买船、买拖拉机花的都是这笔金币；另有对局结算 / 晋级赛名次 / 每日任务给的金币。开宝箱只吃**宝箱钥匙**，钥匙来自成就 / 发球机里程碑 / 段位奖励 / 每日钓鱼任务 / 晋级赛名次 / 小黄龙转盘；开箱还会出 🧩 **星尘碎片**（约 1/5 的抽是「袋子档」），它只能在宝箱的兑换区换指定装扮
- **角色图层全局统一**：身体(2) → emoji 头(3) → 帽子/宠物(4)，Phaser 场景与大地图 Canvas2D 走同一份 `drawRigGraphics`，任何地方的角色长得都一样

源码约 2 万行、124 个 ts/vue 文件。

## 界面规范与大地图

界面在 2026-10 做过一次「外壳 + 尺寸规范」重构，皮肤是**奶黄 Liquid Glass**，交互原型在 `docs/ui-prototype.html`（独立静态页，不参与构建，浏览器直接打开即可）。

- **入口改成大地图**：`/` 是一块 2400×1400 的俯视平面（`src/views/WorldView.vue` + `src/game/world/zones.ts`）。左下角虚拟摇杆或 `WASD` 在平面上自由走动，走到区域圈内**按 E** 或点**右下角弹出的「🚪 进入 xxx」大按钮**（收购商跟前则变「💰 和农场主换钱」；手机的主入口，层级压过摇杆热区、不会误触走动）进入对应玩法（训练场→单机、联机球场→联机、攀岩崖、**理发店**、海湾→潜水、矿洞、**商店→活动/宝箱**、**宠物店→买宠物**、晋级赛馆、名人堂、**赛事中心→观战台**）。**视距可调**：双指捏合（手机）或右缘一列「＋ / 百分比 / －」按钮（点百分比复位），范围 55%~140%，**镜头始终以自己为中心**、记在本机（`bmt-world-zoom`；世界比视口还小时自动居中）。左上角是 **比赛训练区**（训练场 / 联机球场 / 晋级赛馆 / 名人堂 / **赛事中心**，五家排成一块 1000×620 的地），右上角是 **活动和商场区**（理发店 / 商店 / 宠物店），左下角是 **赚钱区**（矿洞 / 农场 / 海湾），攀岩崖单独摆在右下（见下面的「地块」）。**赚钱区的农田旁边站着一位拿鞭子的农场主**（NPC）：他同时是**收购商**——靠近他会骂一句「想赚钱？下地干活去——光站着可没人给你钱」，然后**按 E（或点他旁边的「💰 换钱」）打开收购站**，把仓库里的棉花 / 矿石 / 鱼换成金币（`components/TradePanel.vue`）。靠近时他只有 **15%** 的概率顺手抽你一鞭（震屏 + 把你朝外拍退 + 冒星星，**不掉任何东西**，9 秒冷却），**交易时他不动手**。NPC 的定义在 `src/game/world/npcs.ts`（`trader: true` 的会被当成收购商；摆位要落在别的区域圈之外，否则会和「按 E 进入」抢注意力）。原来的首页还在 `/home`（段位 / 成就 / 背包 / 宝箱 / 好友 / 个人主页 / 设置）。
- **地块（`zones.ts` 的 `WORLD_DISTRICTS`）**：把一伙相关的玩法圈在一起，现在三块——左上角 **比赛训练区**（训练场 / 联机球场 / 晋级赛馆 / 名人堂 / 赛事中心）、右上角 **活动和商场区**（理发店 / 商店 / 宠物店）、左下角 **赚钱区**（矿洞 / 农场 / 海湾）。地块是纯地面装饰（虚线框 + 名字，`pointer-events: none`，不会挡住区域那圈虚线大圆的点击），地上那几条小路是 `WorldView.vue` 里写死的 `.world__path`。进哪个玩法仍然看走过去的是哪个圈（`ZONE_RADIUS`），所以挪区域坐标时记得两件事：圈留在框里、彼此不重叠，而且**区域中心不能贴着地图边**——玩家坐标被夹在 `[70, W-70]`，`y > 1330-130=1200` 才走得到（攀岩崖就是这么定的 1235）。
- **🎪 活动弹窗**：大世界右侧只有一个活动入口（有券或还有今日挑战次数时点一个小红点），点开是「**左 tab + 右画面**」——左边四个 tab 只写简化信息（小黄龙：券数；哥斯拉：今日次数；外星人：今日次数 / 最高击杀 / 里程碑；连击里程碑：最高连击 / 解锁档数），右边显示选中那张活动的画面：角色直接用游戏同一份绘制（`CharacterPreview`，小黄龙 / 哥斯拉 / 外星人形象），底色按活动换天地两色（`art` 那对颜色），下面是一句说明 + 信息胶囊 + 「去哪儿」。
  **点画面就是进入**（跳 `/nailong`、`/godzilla`、`/alien`，连击里程碑是弹进度面板，不跳页）。四个活动都定义在 `WorldView.vue` 的 `EVENTS` 里，加一个活动就是往数组里加一条。
- **理发店**（`/barber`，`src/views/BarberView.vue`）：外观自定义从首页搬到了大地图上的这家店，**试穿免费、点「确认修改」才收 ¥`BARBER_COST`（默认 100）**；不确认就离开会自动还原成进店时的样子，金币不够也能进店试（确认按钮置灰并提示差多少）。店里能改表情 / 球拍与拖尾配色 / 球场主题；头饰、翅膀、披风、光环、宠物、球拍皮肤、坐骑、命中特效仍在「背包」里装备。
- **地图上的角色=游戏里那个角色**：地图不是 DOM 拼的色块，而是用**游戏同一份绘制**画在一张 `<canvas>` 上（`src/game/draw/canvas2d.ts` 把 Phaser Graphics 指令映射到 Canvas2D，再调 `draw/rig.ts` 的 `drawRigGraphics`）。所以全部装扮（哥斯拉形态、光环、披风、翅膀、头饰、宠物、拖尾色、**球拍皮肤**）在地图上跟着背包走，光环 / 披风 / 翅膀还在摆动；角色朝移动方向翻面，球拍斜举在身前。
- **邀请好友一起逛**：左上角「模式设置」里「建房一起逛」开一个房间（房号 5 位），再点「邀请好友」——对方接受后会**被送到 `/`** 并自动进房，两个人就同时站在这张地图上（左侧列表里会写「在地图上」，不再显示申请加入）。也可以直接把房号发给对方，用「加入好友营地」进去。实现见 `src/composables/useMapSession.ts`：连上后互发一次 `hello`（名字 + 装扮，和联机对战同一套 `sanitizeCosmetic`），之后 12Hz 发 `mapPose`，对方位置做插值，所以走动是顺滑的；客人第一次收到房主坐标时会自动站到他旁边。
- **邀请怎么知道该送你去哪个页面**：邀请消息带一个 `kind`（`match` / `map` / `fish` / `mine`，服务端只做白名单转发），接受后 `App.vue` 按它跳转，对应的页面再用 `lobby.consumeInvite(kind)` 取走房间号——所以接一个地图邀请不会被塞进对战匹配里。
- **在线好友列表是真的联机数据**：每个客户端在**路由一变**就把「我在哪个界面 + 我的房号 + 是否允许加入」上报给大厅（`state` 消息，见 `server/lobby.mjs` 的 `SCENES` / `broadcastState`）；大厅只在**互相关注的好友之间**转发（`watch` → `state`），`stores/lobby.ts` 收成 `states`，`App.vue` 一个 `watchEffect` 汇总进 `presence`。好友的实时状态显示在**右上角「好友」面板**里（大地图左侧的独立在线面板已移除）。
- **联机不用先建房**（统一后的好友流程）：好友码互加之后，**右上角「好友」面板**就是唯一的联机入口——列表里每个好友都带着状态（`🧭 在大世界` / `🏸 在联机对局` / `🤿 在海湾潜水` / `⛏️ 在矿洞` / `💤 离线`），能加入的直接点「**加入**」进他所在的模式，不能加入的按钮**置灰并把原因写在旁边**（「对方关掉了『允许好友加入』」「哥斯拉 Boss 战进行中，无法加入」「还没开房，先邀请他吧」…）。「能加入」的唯一判据是 `src/game/scenes.ts` 的 `joinInfo(scene, room, online, allowJoin)`——scene / room / allowJoin 全部来自大厅同步，本地不猜；`SCENE_KIND` 决定哪些界面是「可以一起玩」的（地图 / 对局 / 海湾 / 矿洞），其余界面各自给一句 `NO_JOIN_REASON`。
- **点「加入」= 直接进房**：`stores/lobby.ts` 的 `requestJoin(id)` 把对方的房号挂进 `pendingJoin`，`FriendsPanel` 顺手 `router.push` 到他所在的页面，目标页面照常 `consumeInvite(kind)` 入房——所以既没有「申请 → 等同意」，也没有「创建房间 / 输入房间码」这一步。
- **允许好友加入（隐私开关）**：设置 → 联机 里的「允许好友直接加入我」（`bmt-allow-join`，默认开）；关掉后 `state` 里的 `join: false` 会同步给好友，他们那边的「加入」置灰并写明原因。仍然是**点「邀请」就能让他过来**。
- **一间房走遍所有玩法**：房主建房后房号记在 `lobby.room` 里，**换页面不换房号**（`hostOpen(hooks, wantCode)` 支持指定房号）；访客接受邀请或被「申请加入」时记下 `following = 房主 id`，之后**房主换界面，访客自动跟过去**（`App.vue` 里 watch 房主的 `scene` → 路由 + 把房号挂进 `pendingJoin`，目标页面照常入房）。所以要一起玩只需要建**一次**房。
- **邀请好友不用先建房**：右上角「好友」面板点「邀请」，若当前没有房间，页面会**自动走一遍建房流程**（`friends-ensure-room` prop，各页面把自己的建房逻辑接进来，`composables/useInviteRoom.ts` 负责等房号），房号一到就发邀请——大世界 / 联机 / 潜水 / 采矿四个场景都支持。
- **一个图形陷阱（已修）**：Vue 里用**裸 `<template>`** 当包裹层会被编译成**原生 `<template>` 元素**，浏览器不渲染它的内容——联机大厅那一整块卡片曾因此「存在但看不见」。现在联机大厅是平铺的兄弟节点，改这页时别再加回裸 `<template>`（要包就用 `<div>` 或 `v-if` 写在元素上）。
- **一个 Phaser 陷阱（已修）**：在**还没显示出来的容器**里 `new Phaser.Game()`（比如容器是 `v-show` 控制的，点「开始」时 DOM 还是 `display:none`）——ScaleManager 拿父节点量到 **0×0**，canvas 就一直按 0 尺寸挂着，只能等它**每 500ms 一次**的父节点尺寸轮询自己纠正，表现就是「进去半天才有图案」。哥斯拉来袭就是这么踩的：`start()` 里 `playing = true` 之后要 `await nextTick()` 再启 Phaser。其它几个 Phaser 页面（矿洞 / 农场 / 潜水 / 攀爬 / 联机）都是容器**常驻**、`onMounted` 里启，所以没这问题。
- **固定像素 UI**：所有控件尺寸走 `src/style.css` 里的 `--ui-*`（按钮 36·44·52 / 图标 34 / 芯片 24 / 面板宽 200），**桌面与手机同一套尺寸，不再按断点缩放**；只有画面自适应铺满。可用性口径：Web 指针目标 ≥ 24px（WCAG 2.2 AA），相邻目标间距 ≥ 8px。
- **统一外壳，没有顶栏**：`src/components/ui/PageShell.vue` 只保留两处浮层——**左上角「退出 + 模式设置」**、**右上角一排横向按钮**（可收成一个「更多」），中间整块都是游戏画面。
- **右上角是文字按钮，不是图标**：这一行现在写的是字（「个人主页 / 成就 / 段位 / 背包 / 宝箱 / 好友 / 设置 / 收起」…），行内按钮宽度自适应、太窄时自动折行（`.hud-icons__row` 的 `flex-wrap`）。各玩法页通过 `#icons` 插槽往里塞自己的按钮。
- **每个页面的设置内容都和大世界一样**：`PageShell.vue` 直接内置了这一段 + 对应的弹窗（**成就 / 段位 / 背包 / 宝箱 / 好友**，加上外壳自己的 **个人主页 / 设置（兑换码）**）。所以联机对局、单机练习、潜水、采矿、攀爬、孵化屋、大世界这些用了外壳的页面**不需要各写一套**，天然一致；大世界那边原来重复的那一套已经删掉。页面自己的按钮（坞里的「邀请好友」等）想开外壳的面板时，用 `ref` 调 `shell.openFriends() / openBackpack() / openAchievements()`。好友面板要看场景：外壳有 `friends-kind / friends-code / friends-can-invite` 三个 props（大世界传 `map` + 房号，联机传 `match` + 房号）。首页 `HomeView` 不走外壳，但它的「更多」里有同样的入口。
- **商店与宠物店（大地图上的两栋新楼）**：`/shop`（`src/views/ShopView.vue`）是 🏪 商店——店里可以走动，四个柜台：**🎪 活动告示板 / 🏅 荣誉柜台 / 🪙 金币商店 / 🎁 宝箱柜**（走近按 E 或点柜台弹面板，外壳与首页的宝箱入口都改成跳这里）；`/petshop`（`src/views/PetShopView.vue`）是 🐾 宠物店——3 个展示位明码标价卖现成宠物，每小时整点补货，普通/稀有常见、史诗/传说小概率上架（宠物蛋系统已移除）。
- **金币商店（`CoinShopPanel.vue`）**：宝箱池里 **3★ 及以下的 `gacha` 物品**（低星特效 + 低星头饰 / 拖尾 / 球拍皮肤…）拿出来**用金币直购**（¥200 / 450 / 900），按部位分页、没拥有的排前面。高星（4★ / 5★）只能从宝箱出；**`source: 'chest'` 的宝箱专属连 3★ 以下也不卖**（"宝箱出的东西就得开箱拿"）。清单与定价在 `items.ts` 的 `COIN_SHOP` / `COIN_PRICE_BY_STARS`，改一处即可。
- **金币商店专属款（10 款角色形象 + 10 款坐骑）**（`source: 'coin'`）：**1★ ¥800 / 2★ ¥1800 / 3★ ¥3600**（比同星级普通货贵一截，是「整套皮肤 / 整只坐骑」，价格单独放在 `items.ts` 的 `COIN_EXCLUSIVE_PRICE_BY_STARS`，要攒一阵子赚钱区的收入才买得起），**不在宝箱池里**（开箱抽不到、也不会稀释宝箱的类别分布，所以 `COIN_SHOP` 是「`source:'coin'` 或 `gacha` 且 ≤3★」两来源拼出来的；`chest` 宝箱专属不在其中）。10 款造型各不相同，但都靠同一套小工具做出动态——`pulse()` 呼吸/摇摆、`blinkOpen()` 眨眼、`cuteEyes()` 一对会眨的圆眼（见 `draw/character.ts` 底部）：
  | 形象 | 星 | 动态 |

- **液玻与果冻**：玻璃 = 半透明白 + 双色内边 + 指针跟随的镜面高光（`--sheen` + `--mx/--my`）；按钮按下 `scale(.94,.88)` 挤压、松手沿 `--ease-jelly` 过冲回弹；`prefers-reduced-motion` 下全部关闭。

## 操作

（羽毛球、采矿共用同一套操控；潜水是 8 向游动，攀爬见各自小节）

所有模式的操作逻辑完全一致：**移动**用键盘 / 左摇杆，**挥拍**用鼠标 / 右摇杆，全部走同一套 `RacketTracker`（鼠标位移 → 拍头偏移 + 平滑速度 + 瞬移保护），手机端也共用同一个 `TouchControls` 双摇杆组件。

| 操作 | 桌面 | 手机 |
|---|---|---|
| 移动 | `A` / `D` 或 `←` / `→` | 左摇杆左右推 |
| 起跳 | `空格` / `K`（也兼容 `W`） | 左摇杆**上推** |
| 挥拍 | **移动鼠标**（碰到球自动击出） | 右摇杆（碰球自动击出） |
| 重开一局 | `R` 或点击按钮 | 点击按钮 |
| 表情 | 右上角 🙂，或 `1`~`8` 直选 | 右上角 🙂 |
| 摇杆设置 | 设置里可开「桌面端也显示摇杆」 | 设置里可开「**自由摇杆**」（按下处出现、松手消失）与「**摇杆大小**」（0.7×~1.5×） |

手机上对局时整个屏幕就是一页：球场铺满视口，按钮只有左上角（退出 / 模式设置）和右上角一排图标，页面不会滚动。

**出球规律**：挥拍方向决定球的去向（往上抹=挑高/高远，平扫=平抽，下砍=扣杀），挥拍速度决定出球力度。触球点低于网高时会被强制托起，不会打下网。

**发球规则**：发球阶段双方都会被挡在离网一定距离外（画面上有虚线标出这条界），过不去；发球必须在重置后稍作停顿、并**向前或向上**挥出才生效（向后收拍、纯站位移动不会误发球）。

**打击感**：击球会按**实际挥拍速度**触发屏幕震动（时长与幅度随速度提升），并按击球类型加权——扣杀最重、高远次之、平抽更轻、挑球最轻，轻碰（速度低于阈值）完全没有震动。触发扣杀时球的位置会弹出「扣杀！」浮动文字，力气越大字号越大。

## 手机端界面

- **球场铺满屏幕**：对局页在手机上把画布拉伸铺满整个可用区域（不做 16:9 留白），画面比例不足时轻微变形换取满屏。
- **没有顶栏**：左上角是「← 退出」和一个显眼的「模式设置」按钮（强调色描边），右上角是一排小图标（可收成一个箭头）；画面因此是整块的，比分/提示都由游戏自己画在画布上。
- **模式设置面板**：所有模式的功能项（模式/难度选择、摇杆布局、潜水三件装备升级、出海、建房/加入营地、邀请好友、重来、连接状态…）都在这个面板里，默认收起，点一下展开、点面板外或 `Esc` 收起。
- 多个触点同时按下的支持是通过 `this.input.addPointer(3)` 打开的（Phaser 默认只跟踪 1 个触点，缺了它就没法一边移动一边控拍）。

## 单机：对战 AI / 发球机

「单机练习」页面顶部可以切两种模式，难度档会同时切换：

| 模式 | 说明 |
|---|---|
| **对战 AI** | 标准 11 分制，AI 带预判误差 / 反应延迟 / 接触误差三档（难度档可切换） |
| **发球机** | 无限练习，**没有难度选择**：右侧一台发射器按节奏喂球，**计连击**：接到 +1，落地归零，历史最高单独记录 |

发球机的参数全部在 `WorldConfig` 上（`machineInterval` 出球间隔 / `machineSpeed` 球速 / `machineSpread` 落点散布 / `machineAimAt` 是否瞄人 / `machineAngle` 出球仰角），喂球落点用**二分速度**解出来——固定仰角下射程随速度单调，不会掉进 45° 峰的另一侧，而且解算用的是模拟器同一个积分器，所以落点是真的准。

**渐进难度**：发球机模式不再让玩家选难度，改为 `rampMachineDifficulty()` 在每次喂球前按当前连击数调参——出球间隔缩短、球速提升、落点散布变大、仰角变高，连击越高越难；失误落地连击清零后参数自动回落。上限有封顶（间隔 0.45s / 球速 2600 / 散布 430）。

**连击里程碑「复古训练房」套装**：连击每达到 **10 的整数倍**（10/20/…/100）解锁一档**活动专属装扮**（固定对照表 `items.MILESTONE_REWARD`，不进宝箱池）：10 教练帽 / 20 涡轮双翼 / 30 冠军毛巾 / 40 训练聚光灯 / 50 复古木拍 / 60 荧光训练球 / 70 节拍器弧线 / 80 砰！贴纸 / 90 场地标线，**100 连击解锁「发球机教练」形象**；每档另外给 **1 把宝箱钥匙**。详情在右侧 🎪 活动弹窗的 🎯 面板：历史最高连击进度条 + 每档奖励 + 已解锁装扮的图标回显。失误/漏接连击清零（发球机自己挂网不算）。**哥斯拉皮肤已移到「哥斯拉来袭」地狱难度掉落**，老存档按旧规则自动补发。

发球机是独立的 `WorldMode = 'machine'`，机器没有身体（不占位、不挥拍），第一版**故意不放进乐趣模式的投票池**——party 靠 `phase === 'gameover'` + `winScore` 结束回合，发球机没有比分，放进去会卡死回合流程。

## 攀爬挑战

主页第四个按钮，**独立路由 `/climb`、独立 Phaser 实例**（因为这个玩法需要真正的刚体求解器，羽毛球不需要）。

用羽毛球拍去攀岩。**人物是有物理的**：会摔、有摩擦，可以直接 `A`/`D`（或 `←`/`→`）行走；**球拍 360° 跟随鼠标**，并且和挥拍一样**会伸出/收回**（指针远就伸出去够，近就收回来）。把拍头撑住地面或岩壁、再转动它，反作用力就能把自己顶上去、勾上岩台。

实现要点（也是踩过的坑）：

- **两套物理并存**：羽毛球是自写的运动学积分，攀爬用 Matter。Phaser 4 默认包里就带着 Matter，所以**没有新增依赖**；Matter 通过 `this.matter` 暴露原始 API（`bodies` / `constraint` / `composite`）
- **人物与球拍共用外观**：绘制原语抽到了 `src/game/draw/`，两个场景画出来的是同一套角色和球拍皮肤
- **手臂是变长度约束**：`constraint.length` 每步都被求解器重新读取，平滑地改它就能让手伸缩，**不会产生冲量尖峰**
- **自身体和球拍共用一个负碰撞组**，否则手臂转到一半会被自己的躯干卡死，转不满 360°
- **单位陷阱**：Matter 的 `body.velocity` 是**像素/步**不是像素/秒，差 60 倍；力矩则是 `Δω = torque/inertia · Δt²`（Δt 以毫秒计）。这两处弄错一个，角色要么动不了要么上天

手感旋钮全部集中在 `src/game/climb/ClimbScene.ts` 顶部（`ARM_KP/KD/ALPHA`、`WALK_SPEED`、`BODY_R`、`ROD_LEN`…），改完按 `R` 重开即可。

## 海湾 · 潜水抓鱼

大地图上的 🤿 海湾，独立路由 `/fish`、独立 Phaser 实例（`src/game/dive/DiveScene.ts`，数值在 `src/game/dive/fish.ts`）。

世界是**竖着的一片海 + 左边一片沙滩**：y = 0 是水面，越往下越深、鱼越贵。左摇杆 / WASD **8 向游动**（上推 = 上浮，不按会缓缓下沉），相机跟着人走。

- **岸上**：出生就在沙滩上（不是一上来就在水里）。沙滩从左边高处斜降到水边，岸上有**装备店**（木屋，门口按 E 开店）、木栈桥和（买了船之后的）船；天空、太阳、云都会跟着镜头抬起来。岸上按普通走路 + 空格跳的陆地物理，往右走出沙滩就落进海里，往左游回来就能上岸——岸上氧气自动回满。
- **升级只能在岸上**：装备店只开在沙滩上，游在水里时「装备店」按钮是灰的（点了会提示先上岸）。站在门口会高亮小屋并提示按 E。

- **抓鱼**：右摇杆 / 鼠标把球拍（鱼竿）的拍头**指到鱼身上**就勾住，之后**一直朝着鱼的方向**才能把线收回来（鱼身上有进度环）；鱼拖着线跑，跑出范围就脱钩。这套追踪仍是羽毛球那套 `RacketTracker`，所以手感一致。
- **氧气**：屏下那条蓝条，浮回水面（y ≤ `SURFACE_BAND`）回满。**越深越费气，而且是平方曲线**：`耗气/秒 = 1 + 0.00055·深度px + 1.4e-7·深度px²`（`OXYGEN_DEEP` / `OXYGEN_DEEP2`）——100m 约 1.7/s、200m 2.7/s、320m 4.2/s、500m 7.3/s、640m 10.3/s，所以「直上直下摸一趟」的代价是 100m 8 秒、200m 21 秒、500m 107 秒、640m 181 秒。**耗尽 = 这一趟白潜**：背包里的鱼与身上挂着的宝箱收获**全丢**，屏幕一黑（相机 `fadeOut`），人在沙滩上醒来（氧气给满）——所以在深处贪最后一条鱼是有代价的。
- **鱼在哪**：**先定深度、再定鱼种**（`DiveScene.spawnRandomFish`）——按 `DEPTH_ZONES` 的权重抽一层（浅层 18%、中层 42%、深海 40%），再只在这一层住得下的鱼种里按 `weight` 挑一条，落点取「这段深度 ∩ 这条鱼的活动带」。所以**浅层只有零星几条，鱼大多在中层与深海**，好东西都得往下潜。
- **宝箱收获要「入港」才算到手**：开海底宝箱（点它 / 按 E，`onChest`）先只把奖励**挂**在 `FishView` 的 `pending` 里（画面左上会有「🎁 未入港」小卡），**踩到沙滩那一刻**才真正发到手（`bankLoot()`）；氧气耗尽连这些一起没。金币奖励的宝箱也一样——不落袋为安。
- **背包**：条数 + 总重量双上限，塞不下就提示"回岸上把鱼交给农场主"。
- **渔具**：决定钩子半径、**能拉住的体重上限**与收杆速度；渔具不够的鱼会「拉不动」挣脱。
- **危险**：🪼 水母（碰到掉 26% 氧气 + 短暂失控）、🦈 鲨鱼（进范围就追，撞上抢走一半渔获后撤退）、暗流（把人往一侧推）。
- **鱼怎么变钱**：**鱼不再在船上卖**——踩上岸那一刻这一趟的渔获转进**鱼仓**（`progress.fishBox`，`bankDiveBag()`；换海 / 离开页面时也会兜一次，不会白抓），之后回大世界的赚钱区交给**农场主**按条收购（`progress.sellMaterials('fish')`，每条的钱是抓到时算好的 `value`，闪光 ×5 / 鱼王 ×3 已含在内）。氧气耗尽照旧算白潜（那一下袋子里已经被清空，什么都入不了仓）。
- **升级要花金币**（金币来自把材料交给农场主），三条线各自 **1~8 级**（¥300 / 700 / 1400 / 2400 / 4200 / 7000 / 11000，`UPGRADE_COSTS`）——**氧气罐**（36s → 232s，`oxygenMax`）、**背包**（6 条/14kg → 27 条/77kg）、**渔具**（上限 4kg → 102kg）。等级上限从 5 抬到 8 就是为了深海：640m 那一趟往返要 181 秒氧气，满级才够。
- **出海 = 岸边那条船**：没有「出海选项页」了。沙滩尽头的木栈桥可以走上去，桥尾拴着一条船 —— **点船**（或站到船边按 `E`）弹出船上的小卡片：没买就先「买船」（`BOAT_COST` ¥2500），买了就列出现在能去的海岛（按渔具等级过滤）。船一直在岸边；买了之后立刻换成有帆的船，「出售」牌子也收起来。海岛各有深度、鱼池与危险：
  | 海岛 | 船费 | 渔具 | 海床 | 特点 |
  |---|---|---|---|---|
  | 近岸浅滩 | 免费 | Lv.1 | 200m | 小鱼多、水母少，练手；氧气罐 Lv1 就能摸到底 |
  | 珊瑚环礁 | ¥600 | Lv.2 | 320m | 鱼密度高、水母密；200m 深潜成就的第一站 |
  | 深海沟 | ¥1200 | Lv.3 | 500m | 金枪鱼与鮟鱇；氧气罐 Lv4 才够潜到底 |
  | 沉船湾 | ¥2000 | Lv.4 | 640m | 石斑 + 深海龙王；往返要 181s 氧气，得满级氧气罐 |
- **屏幕右侧有潜水深度进度条**：金色刻度线是当前位置，到底部黄线 = 海床。
- **鱼的大小随体重变化**：同种鱼按体重在 **0.6×~1.8×** 平滑缩放（`sizeScale`），判定半径同步。
- **✨ 闪光鱼**（2%）：金色发光变体，价值 ×5，图鉴标 ✨；**👑 鱼王**（2%）：超大个体、游速 ×1.4、价值 ×3，抓住有专属成就「鱼王猎人 / 王中王」「金光一闪 / 星光收藏家」。
- **🎁 海底宝箱**：海里随机刷（同屏 1 个，20~40s），靠近按 E 或点一下——开出金币 / 未拥有的装扮 / **闪光鱼饵**（消耗后下一条鱼必闪光）。
- **📋 每日钓鱼任务**：每天随机一条（抓 3 条 20kg+ / 抓 5 条沙丁鱼 / 抓 1 条闪光鱼…），侧栏任务卡推进度，完成领金币+荣誉，跨天自动换。
- **装备上身高**：氧气罐（背后）、背包（腰间）、鱼竿（手中，随等级变大换色）只在潜水场景显示，退出不跟随。

## 采矿场

主页第六个按钮，独立路由 `/mine`、独立 Phaser 实例（`src/game/mine/MiningScene.ts`）。

角色面前是一座**矿石山**：进图时生成 25 块方块矿石叠成的山（底行 9 块，往上每行减 2），矿种逐块加权随机——石头/铁矿常见，金矿较少，钻石矿稀有。挥拍砸它就会掉耐久。**必须真的挥动**才有效：拍头速度 ≥ `SWING_MIN`（550 px/s）且速度方向朝着矿石（点积为正）才算一次击打，静止把拍子贴着石头完全无效；击打有 0.22s 冷却。**整座山挖空后 1 分钟重新生成**（原地显示倒计时）。

| 矿石 | 耐久 | 给几个「矿石」 | 换成钱（¥8/个） |
|---|---|---|---|
| 石头 | 3 | 1 | ¥8 |
| 铁矿 | 6 | 2 | ¥16 |
| 金矿 | 10 | 4 | ¥32 |
| 钻石矿 | 16 | 10 | ¥80 |

- **矿石是实体**：画面上就是一块能站的方块——从侧面撞上会被顶开（`resolveRockCollision()`，按身体半宽算），从上方落下会**站在矿石顶上**（顶面按画的方块取平），走过头会掉下去；不会再穿过矿石。
- **砸矿给的是「矿石」材料，不是金币**（`ORE_KINDS[].units`）：越硬的矿给得越多（石头 1 / 铁矿 2 / 金矿 4 / 钻石 10），矿石先记进 `progress.ore`，拉去赚钱区交给**农场主**按 ¥8/个 收购才变成钱——所以挖矿本身不再直接进账。
- **画面上不写耐久与收获**：左上角那行 HUD 已去掉（它还会和左上角的退出/模式设置按钮打架）。耐久直接看**裂纹**（掉血越多裂纹越多），收获看破坏瞬间的反馈。
- **破坏瞬间的收获反馈**：矿石图标（🪨）+ 跳动的 `+N`——先回弹缩放弹出、再向上跳一下、最后飘起淡出（`orePop()`，用 Phaser tween）。
- **矿石山是实体**：每块方块都能站、能挡（从侧面撞上被顶开，从上方落下站上去）；整座山挖空后原地显示「矿山恢复中」倒计时，60s 后重新生成。碎石飞溅同样用羽毛球的重力 + 二次阻力积分器，落地还有衰减反弹。本场累计仍显示在「模式设置」面板里。联机与潜水同款：各挖各的山，`minePose` + `mineBreak` 两条消息（对方的收获仍用文字提示，避免和自己的金币特效混淆）。

工程上的三个决定：

- **命中特效拆成模块**：前置的 93 个 painter 按 `basic/shard/nature/energy/toy/odd` 分目录，加一个注册表项就能上新特效，不用再动 `GameScene`。当时是从一个 1356 行的 `switch` 机械抽取的，并用脚本逐字校验过抽取前后一致

- **角色绘制抽成共享装备**：`src/game/draw/rig.ts` 的 `createPlayerRig()` 把「居中表情脸 + 身体 + 手臂 + 球拍（含挥拍拖尾弧与甜区光环）」打包成一个组件，逐行复刻 `GameScene` 的画法；羽毛球、攀爬、潜水、采矿四个场景都用它，外观（哥斯拉皮肤、U熊、翅膀、披风、球拍皮肤…）到哪里都一致
- **U熊的肚皮不只是画出来的**：它是一块真的会改球路的判定——`World.skins` 记着双方形象，`simulation.ts` 的 `stepShuttleSlice()` 在球撞到肚皮圆（`BELLY_R/BELLY_CY`）时按法线反射（`BELLY_REST` 0.92，几乎不掉速）并抛出 `belly` 事件，场景再据此驱动**果冻形变**（阻尼弹簧 `stepBelly`）与「弹！」浮字。放在模拟层而不是渲染层，是因为它会改变轨迹：两边都按「自己 + `hello` 收到的对方」写同一份 `skins`，房主的权威模拟和访客的预测才不会分叉
- **网页界面也复用这份画法**：`src/game/draw/canvas2d.ts` 把 Phaser Graphics 指令映射到普通 `<canvas>`，于是大地图上的角色（`WorldView`）和背包/外观页的角色预览（`CharacterPreview.vue`）都跑同一份 `drawRigGraphics`——以前预览是自己一套 DOM + SVG 近似（另一套身体、帽子、翅膀），所以「背包里和地图上不一样」，现在只剩一份实现，改一处到处一致
- **U熊的肚子、老皮的屁股：走路时会跳**（`CharacterPose.move`）：`GameScene.drawPlayer` 把 `|vx| / PLAYER_SPEED` 当"移动强度"传进角色姿态，`drawUBear` 用它让**大肚皮一颤一颤**（两条腿一步一拍：150ms 上下颠 + 肚子独立抖，停下只剩呼吸起伏），`drawLaopi` 用它让**两坨钢铁屁股各自相位弹跳**（站着慢慢颠、走起来跳得更高更频，落地时钢板压扁、铆钉拧一点、帽顶小球一起颠）——两套动画都不碰判定，U熊那套「把球弹开」的肚皮圆位置仍与 `simulation.ts` 的 `BELLY_R / BELLY_CY` 对齐

## 活动与进阶玩法

### 农场（大地图 🌾，`/farm`）
3×8 棉花地，**把球拍挥到棉花上就采摘**（判定与矿洞同款：拍头要快且朝着棉花），**一朵 = 1 个「棉花」材料**（`MATERIALS.cotton`，旧版那种「每朵随机 ¥6~18」已经取消），采完 60s 重生（存档持久）。采摘等级（¥180/520/1400/3600，1~5 级）决定一次挥拍摘几朵；**拖拉机 ¥3000 买断**后可「一键收全地」（收成也是棉花材料）。

棉花**不直接换钱**：它进 `progress.cotton`，要拉去赚钱区交给**农场主**按 **¥5/朵** 收购（一片地能收的量比矿多，所以单价压得比矿石低）。

### 晋级赛馆 + 荣誉点（`/arena`）
16 人单败淘汰。**赛事分七档，级别 = 报名费**：🌱50 / 🎋100 / 🌅200 / 💨400 / 🪨600 / 🔥800 / 👑1000（门槛 0~920 积分逐档解锁）；**每一档有自己的赛事名池**（如 50 赛：新芽杯 / 小白公开赛 / 菜鸟杯 / 社区热身赛…），每届从池里随机取一个。晋级赛与世界赛用**同一套七档**（`ARENA_TIERS`，两边同步）。低档抽临时弱手、高档从名人堂抽（**最高两档必定有皮泽恩**）。名次结算：金币按 `goldForPlace`、积分按 `pointsForPlace`，**荣誉点**只有冠（40）亚（25）季（15）才有，再乘档位倍率（×1~×3）。「4 强」即**季军**（半决赛输的两位并列，没有三四名决赛）。

### 对局体力值（`simulation.ts` / `ai.ts` / `constants.ts`）
为了终结「AI 太稳、一分打很久」：正式对局（单机 / 晋级赛 / 联机 / 观战）引入**体力**（0~100）——
- **消耗**：满速跑动每秒 -9、起跳 -3.5、每次击球 -5；站着/慢走**缓缓回**（每秒 +4.5，跑动中只回 15%）；
- **恢复**：每分之间（发球前）一次性回 20；发球机 / 颠球挑战不消耗；
- **低体力影响**：移动速度最低打 **65 折**、击球力度最低打 **72 折**（杀球变推球）、AI 非受迫失误率最多再叠 **+16%**（保底 5% → 空体力约 20%+）；
- **HUD**：画布顶部左右各一条体力条（本地玩家的高亮描边，低于 30% 变红），观战时两位都显示；联机把体力随快照同步（旧快照当作满体力）。
- 配平实测（双 AI 打 4 分钟）：平均回合约 7 秒、最长 13 秒，长回合被自然终结。所有常量在 `constants.ts` 的 `STAMINA_*`。

### 荣誉柜台（商店里的 🏅，`HonorShopPanel.vue`）
荣誉点的唯一花处：**10 款坐骑**（¥200~1200）+ **3 款特殊形象**（冠军铠甲 800 / 不灭凤凰 1200 / 龙王 1600）。坐骑纯装饰、画在角色脚下、不碰物理（联机安全）。

### 名人堂（大地图 🏛️，`/hall`）
AI 球员排行榜（rating 排序，**传奇 AI 皮泽恩恒定榜首**：五维 95+、rating 2400、金色王冠标识、大肚熊皮肤、高远球+扣杀双满的「传奇」风格）。可以看球员主页、**观战世界赛正在打的那一场**、或点「⚔️ 挑战」直接开一场（胜负照记双方战绩）。

**球员管理（新增 / 退役 / 编辑）**：
- 右上角「➕ **新增球员**」随机造一位新人（名字优先从没被占用的池子里挑）并直接打开编辑面板；
- 每行「⚙️」打开**编辑面板**：改名字、拉五维滑条（技术 / 速度 / 进攻 / 防守 / 弹跳，**改了五维就按综合分把榜单分数重算**，面板上给实时预览）、「🎲 随机换装」换一身装扮（角色预览与游戏同款绘制）；
- 面板里可以「🏳️ **退役**」：人留在名录、战绩与履历保留，但**不再上榜单、也不再参加世界赛**；只对自己新增的球员开放「🗑 除名」；
- 头部「**退役名录 N**」切到退役名单，每行可以「**复出**」把人请回来。

### 球员主页（`components/PlayerProfile.vue`，名人堂 / 晋级赛 / 赛事中心共用同一份）
角色预览（与游戏同一份绘制）+ 名字与风格 + **四张数据卡** + 四维雷达图与数值条：

- **🧮 四张卡**：**总胜率**（红绿圆环，绿=胜率；数据来自球员真实战绩 `wins/losses`，没有战绩就按积分估）、**能力值**（五维平均折成 1.0~5.0 的六边形）、**冠军 ×N**（紫缎带金牌，数字 = 履历里的冠军数）、**最高排名**（月桂 + 数字，1 最好）。
- **🏅 生涯履历（点「冠军」那张奖牌卡展开）**：一行一届，**年月在左**，比如 `2026-10 · 2026-50 小白公开赛(50赛) · 🥇冠军`、`2026-09 · 2026-800 焚天公开赛(800赛) · 🥉4 强 · 负于 疾风侠`（冠军那行写「全胜夺冠 · 赢下 4 场」）。普通赛事叫「**年份-级别 杯名(级别赛)**」；世界赛事没有级别，叫「2026·世界巡回赛」。配色按名次：冠军金 / 亚军银 / 4 强铜。
- 履历由 `game/career.ts` 的 `careerOf()` 算出来：**名字当种子**（所以同一球员在主页 / 名人堂 / 赛事中心看到的完全一致、刷新不变，也不需要存档），**实力（rating）只影响概率**——越强赛事级别越高（七档：50赛→1000赛 → 世界赛事名 世界巡回赛 / 山海公开赛…）、名次越好、冠军越多、最高排名越靠前（传奇球员皮泽恩就是冠军一堆 + 最高排名 #1）。年月是真实日历（最近一届落在近日，往前一路推到跨年）。
- 想加一档名次或改概率曲线：`career.ts` 的 `Placing` / `PLACING_*` / `rollPlacing()` / `pickCup()` / `abilityScore()` / `winRateOf()`。

### 赛事中心 · 观战台（大地图 👁，`/watch`）
**进去是一间电影院**：房间里可以自由走动（手机左摇杆 / 桌面 WASD，相机跟随），墙上挂着一块 **1040×585 的大屏幕**（**正好 16:9**），下面三排共 18 个座位，座位上的观众**由系统自己生成、而且一直在流动**。

- **📺 大屏只播直播**：屏幕上**永远是正在进行的对局**（玩家不参与、「再来一局」与 `R` 键都关掉，见 `GameCanvas :spectate :no-rematch`）。之所以能把 1280×720 的对局投得**满屏不留黑边**，是因为屏幕本身做成了 16:9：Phaser 用 `Scale.FIT` 等比缩放，同样比例就是严丝合缝，投上去比分 52px、名字牌 12px，看得清。屏幕上方的跑马灯写着「哪个杯 · 第几届 · 哪一轮 · 谁对谁 + 🔴直播中」，屏里的比分牌、选手名、「X 获胜」都是对局自己画的。
- **📺 选杯 = 选频道（七档赛事，与晋级赛馆同源）**：右下角「📺 选杯」打开弹窗，**上面一排是七档赛事**——🌱50 / 🎋100 / 🌅200 / 💨400 / 🪨600 / 🔥800 / 👑1000 赛（按名人堂排名切档，**一位选手只打自己档位的杯**，rating 涨了升档、掉了降档；所以绝不会有人同时打两个杯）。每届的杯名从该档**名字池**轮换（如 50 赛这届叫「小白公开赛」、下届叫「菜鸟杯」）。每张卡：杯名 / 第几届 / 参赛人数 / 打到哪轮 / 🔴直播几场 或 ⏳还要多久，点谁大屏就播谁；还有一个「🔊 自动」档自动跟有直播的杯。**下面是选中那个杯的树状图**：同一轮的几场**全部标成 🔴（它们确实同时在打）**，正在直播的场次旁边有 **「👁 观看」** 按钮（点谁大屏就切到谁，大屏正在播的那场标「📺 正在播」）；**没开打的场次显示倒计时**（⏳ mm:ss 后开打），人数不满的签位显示「轮空 · 直接晋级」。
- **坐下**：走到空座位旁边（空位的座垫发蓝光），**右下角出现「🪑 坐」按钮**（手机直接点；桌面也可以按 `E`）。**坐下后镜头会平滑地对准大屏**（像真的在看电影；屏幕比视口高时优先保住上面那条比分行），手机竖屏也能看清画面中央。站起来会挪到旁边的过道上，不会卡进邻排座位；你坐着的位子观众不会来抢，站起来让出后又会被别人坐。座位是实心的，但两块座位之间留了一条窄缝，可以像真电影院那样侧身挤进去坐外侧的位子。
- **观众（系统自己的，不是你的名人堂名单）**：名字 / 外观 / 风格全部由系统随机造（见 `game/world/spectators.ts` 的 `makeSpectator`），和名人堂、自建球员完全无关。**他们一直在进出**：左右两个门口**每 8~15 秒**安排一次「有人进场 / 有人离场」——进门的从门口走到过道、顺着过道走到自己那排、侧身进座位坐下；坐 70 秒~3.5 分钟就起身，沿原路走到门口消失（`Crowd`）。**永远留 ≥2 个空位给你**（`minFree`），刷新页面看到的也是另一批人。
  - **结伴进场**：约 30% 的进场是一对朋友（`pairChance`）——同一个门、一前一后错开半步走进来，坐**同一排相邻**的两个位子。
  - **上座率跟着场次走**：座位填到「座位数 × 档位」就基本不再进人（`Crowd.setLevel`）。档位由**现在播的这场是第几轮**决定（`crowdLevel`）——首轮约 0.5、越往后越满，**决赛坐到只剩 2 个空位**。
  - **鼓掌 / 惊呼**：观众会一片一片地反应（`cheer()` → 头顶飘 👏 / 😮 / 🤩，错开几百毫秒，像一片人而不是整排机器）。直播里**得分**触发鼓掌或惊呼、**扣杀**喊一声，**打完**全场起立式欢呼；待机画面则每隔十几秒来一片气氛掌声。
- **待机画面（这一轮的间隙 / 本届结束）**：屏幕上没有直播时不放比赛——一块亮着灯的空场馆，**屏幕正中是同步倒计时**（本届没打完数「下一轮开打」、打完了数「下一届开打」，每帧重画、永远和真实时刻对得上）。
- **🏟 场地切换**：直播开始后，**大屏正下方一排「场地」签**（本轮同时在打的每场一签，写着双方名字），点谁大屏切到谁（和树状图的「👁 观看」等效）；正在播的那场高亮，新一轮开打自动跟到第一场。

弹窗里的 **🌍 世界赛** + **🏆 我的赛事**：

- **🌍 世界赛（七档赛事同时打，`src/game/world-arena.ts`）**：名人堂球员的淘汰赛，**同时有 `CUP_COUNT`（7）个杯在跑**，一档一个杯（50赛→1000赛，与晋级赛馆同一套 `ARENA_TIERS`，杯名每届从该档名字池确定性轮换）；球员按 rating 排名七等分进对应档。杯型随人数（4/8/16 强），每轮 `CUP_ROUND_MS`（150 秒）；**同一轮的所有比赛同时开打、同时进行**。各杯错开起步（一届 ÷ 7 ≈ 86 秒），所以**任何时刻都有杯在打、常常好几场同时直播**。参赛者与对阵用 `hash(杯+届)` 定死——**纯计算、不需要服务器、刷新也不变**；退役的人不参加。
- **结果怎么定**：到点没被看过的场次用 `simulateArenaMatch` 按五维自动算（**只显示直播**，所以你看到的每一场都是真的在打）；你**真看完的那场**以真实对局结果为准，写回赛程（胜者晋级，两位球员各记一笔战绩、rating 互有升降）——所以看直播是**真的在改变名人堂名次**。想跳过就「⏭ 这一轮直接出结果」。
- 唯一需要持久化的是**玩家真看过 / 快进过的那几场**（`bmt-world-arena`，键里带杯 + 届，最多留 600 条），没看过的到点按五维算、不写库。
- **🏆 我的赛事**：玩家自己在晋级赛馆报名的那一届（`bmt-arena-run`）的对阵树也列在这里，想看自己那届的全貌就来这儿。
- **👥 谁在打哪个赛事**：按**当前选中的杯**列出 16 位参赛者的进程（🔴 正在打谁 / ⏳ 几点开打 / ✅ 击败谁晋级 / 🚪 被谁淘汰）。

### 外星人降临（大世界 🛸，`/alien`）
一局 **60 秒**：飞碟在头顶盘旋（`AlienScene` 里画，带朝下的一束探测光），每 1.35s→0.62s 往下吐一颗**陨石**，每颗里都裹着一个外星人。**拍中陨石 = 把它击飞**（陨石朝球拍指的方向飞出去，里面的外星人算击败 +1）；没拍中的陨石落地，**外星人会爬出来在地上追你**，补拍也算击败。
**越到后面越凶**：吐陨石的间隔按二次曲线收紧（开局 1.35s → 最后一刻 0.3s，`SPAWN_SLOW`/`SPAWN_FAST`）；**没拍中的陨石落地会爬出一个外星人，它会一边靠近一边朝你点射**（落地 1.4s 后开第一枪，之后每 2.6s 一发，子弹能拍掉但不算击杀）。
判定与矿洞同款：拍头速度 ≥ `SWING_MIN`（520 px/s）且朝着目标挥才算一次击打。玩家 **3 颗心**，被陨石砸到、被跑动的外星人碰到、被子弹打中都会掉一颗，掉完提前结束；被打到后有 1.2s 无敌闪烁。
**每天免费 3 次**（隔天重置，失败也消耗）。单局击杀走**十二档里程碑、每 6 杀一档**（`ALIEN_MILESTONES`）：**前两档（6 / 12 杀）给金币**（🪙500 / 🪙1500，早期档位拿得快，给装扮太容易），之后十档各一件专属装扮、覆盖十个部位、每档只解锁一次——飞碟头盔（头饰，18 杀）→ 幽绿信标（光环，24）→ 陨石爆（命中特效，30）→ 飞碟（坐骑，36）→ 星尘拖尾（42）→ 激光切片（挥拍拖尾，48）→ 陨石球拍（54）→ 反重力披风（60）→ 轨道地环（66）→ **外星人形象**（72 杀，几乎得不漏一颗球）。另外每局按击杀给金币（×25）与荣誉点（×2）。

### 哥斯拉来袭（大地图 🦖，`/godzilla`）
Boss 战：哥斯拉站右边（**血条在右上**），朝玩家**直线吐火球**（挥拍朝球挥过去就能拍回去砸它扣血）、**贴地激光**从右往左横扫（跳起来躲）。玩家 3 颗心，被激光扫到/被火球砸中掉一颗，**开场 3 秒倒计时无敌**。每天免费 **3 次**，三档难度自选（简单/普通/地狱：血量 12/18/26 击，金币 400/1000/2500 + 荣誉 20/50/120 + 钥匙 1/2/3 把）。

### 摇杆系统（设置 → 操作）
- **桌面端也显示摇杆**：触屏始终显示；开了这个开关，电脑上全玩法常显
- **自由摇杆**：本体隐藏，移动在左半屏（大地图为左侧区域）按下才出现在手指下（**圆心与触点重合**），松手消失；击球摇杆同样支持（右半屏）
- **大小**：0.7×~1.5×，全部摇杆生效（比赛场景下一局生效）
- 灵敏度：死区 0.15、击球摇杆 1.3× 加成
- **外观只有一份定义**：`src/game/draw/joystick.ts` 的 `JOY`（基准半径 / 圆盘留白 / 把手比例 / 金色 / 按下亮度 / 描边宽度）——大世界的 `components/ui/Joystick.vue` 用它算 DOM 尺寸与把手配色，各玩法画在画布里的 `game/touch.ts` 用它算把手半径与配色，所以**大世界与游戏里的摇杆是一套外观**（唯一差别是 DOM 那层 CSS 毛玻璃，画布里用半透明白近似）。改一处两边一起变。
- **大世界有左右两颗**：左边走动，右边控球拍（`side="left" | "right"`）——推哪边球拍就伸向哪边，松手回到斜举姿势；球拍偏移在 `WorldView.vue` 的 `stepRacket()` 里做平滑，绘制走 `paintAvatar(..., { racket })`。显示条件与左摇杆完全一致（触屏必显、桌面端看「桌面端也显示摇杆」）。

## 乐趣模式（Party）

**联机专属**：主页上「单机练习 / 联机对战」旁边的**「乐趣模式」**按钮进入联机大厅（会自动开启），建房后由房主驱动流程。一局分 3 轮，**每轮开始前投票选玩法**，一轮打完弹出比分榜单。

| 玩法 | 效果 |
|---|---|
| 经典 | 标准规则 |
| 重力加倍 | 球落得更快、跳得更高 |
| 月球重力 | 球飘得很远 |
| 超长球拍 | 拍子更长、更好接 |
| 巨球 | 羽毛球变大 |
| 慢动作 | 全场时间变慢 |
| 疾风 | 球速暴涨 |
| 无网 | 球可以穿过中间 |
| 颠球挑战 | 轮流颠球，比谁颠得多（每人 30 秒，落到地上换人） |

联机时由**房主**驱动流程：房主把候选玩法与本轮结果广播给访客，访客跟随；投票双方各选一个，结果相同即选中，不同则随机取一个，超时自动随机。

物理与规则值全部收敛到 `src/game/config.ts` 的 `WorldConfig`（挂在 `World` 上），所以改重力 / 拍长 / 球大小 / 时间流速都不需要动模拟代码；快照会带上玩法 id，访客据此重建完全一致的配置，保证预测不漂移。

## 联机架构

```
        房主（权威）                        访客
   ┌──────────────────┐             ┌──────────────────┐
   │ 跑完整物理模拟     │             │ 只渲染 + 预测自己  │
   │ 收到输入后结算     │  60Hz 快照   │ 收到快照后校正     │
   │ 30→60Hz 广播状态  │ ──────────► │ 球：本地物理推算   │
   │                  │ ◄────────── │ 60Hz 发送输入      │
   └──────────────────┘             └──────────────────┘
```

用到的四种网络技术：

| 技术 | 用在哪 | 解决什么 |
|---|---|---|
| **客户端预测** | 访客自己的角色 | 自己操作零延迟 |
| **本地物理推算**（dead reckoning） | 访客看到的球 | 球不再是"滞后的快照副本"，去掉约 40ms 滞后 |
| **渲染插值** | 本地/房主的画面 | 60Hz 物理 + 165Hz 显示器不再抖动 |
| **延迟补偿**（rewind） | 房主判定访客击球 | 用 `RTT/2` 前的球位做接触判定，访客不挥空 |
| **表情** | 独立旁路消息 | 不影响物理，发送方立即显示 |
| **轻量位姿同步** | 潜水 / 采矿 / 大地图 | `fishPose` / `minePose` / `mapPose` 12Hz 只传位姿，各玩各的互不干扰（不做权威模拟）；大地图另发一次 `hello` 同步名字与装扮 |
| **彩蛋旁路消息** | 潜水抓鱼 / 采矿出矿 | `fishCatch` / `mineBreak` 纯展示提示，不进物理 |

### 传输选择

1. 先试 **WebRTC 直连**（延迟最低）
2. 4.5~6 秒内没连上，自动降级到 **WebSocket 中继**（走你的服务器）
3. 上次成功的通道会影响下次的等待时长，但**不会永久锁死**

> ⚠️ **实测结论**：PeerJS 内置的 TURN 服务器已失效（DNS 都解析不出），公共 TURN 也全部拿不到 relay 候选。所以国内跨省的家宽（CGNAT）**基本连不上直连**，实际都走中继。中继的延迟 = 两台机器到你服务器的距离之和，**服务器位置比任何代码优化都重要**。

## 部署（Railway）

1. 构建命令 `npm run build`，启动命令 `npm start`（`railway.json` 已经写好）
2. `server/index.mjs` 会自动读 Railway 注入的 `$PORT`
3. **区域选择很关键**：实测 US West 时中继 RTT 约 426ms，换到 Singapore 反而涨到 828ms（Railway 的边缘节点统一从洛杉矶接入，机房搬远了等于绕路）。国内玩家建议换到**香港**的机器（免备案，约 ¥24-40/月）

如果换到香港/自建机器，整个 `npm ci && npm run build && npm start` 就跑起来了，前端和中继在同一个盒子里，**不需要改代码**。

## 已知限制

- **直连基本不可用**：国内家宽普遍 CGNAT，对称 NAT 打不通，只能靠中继。想拿到真正低延迟只能自建 coturn 放在靠近玩家的位置
- **手机摇杆死区**：推得很轻时角色不动（死区 0.15），调 `touch.ts` 的 `DEADZONE` 可改
- **表情用系统 emoji**：Windows / 安卓 / iOS 上长得不一样，低端安卓可能出黑白。要一致就得内嵌 Twemoji SVG
- **联机还没有观战 / 匹配 / 排行榜**：目前只有"建房 + 输入房号"（单机的「观战台」见上面的赛事中心，那是 AI 之间的比赛，不是联机对局）
- **世界赛是"每台机器各算各的"**：届号、参赛者、开赛时间都是种子确定的，所以**赛程表**人人一致；但**被真看过的那几场**结果只存在本机（`bmt-world-arena`），所以两个玩家看到的"这一届冠军"可能不同——要做成一致的得把结果放到服务端
- **服务器权威只在房主浏览器**：房主关掉页面这局就结束了（没有断线重连）
- **攀爬暂不支持手机**：手臂靠鼠标指针定位，手机上还没有摇杆映射；联机也还没接（Matter 不跨机器确定，需要做成 host 权威 + 访客纯插值，不能用羽毛球的预测方案）
- **攀爬手感未定稿**：手臂的力度/阻尼是按"不抖动、不把人弹飞"取的保守值，最终手感需要实际玩过再调
- **潜水 / 采矿的联机只是"同场"**：不跑权威模拟，两边各算各的，只同步位姿与收获提示，所以互不影响也互不竞争
- **手机端球场是拉伸铺满的**：屏幕宽高比不是 16:9 时画面会有轻微变形（换取满屏无黑边）；桌面端仍是等比 FIT
- **晋级赛已实现（vs AI）**：8 人单败淘汰，报名费与奖励按段位配平（`src/game/arena.ts`）；联机版与观赛的对手表演赛还没有
- **大地图房间是 1v1**：PeerJS / 中继都是两方通道，所以一张地图上最多再站一个好友（房主 + 1）。要做「一屋子人」得给地图加一个房间服务器（一条连接广播 N 方位姿），现在的 `mapPose` 协议不用改，只换承载方式
- **在线列表只覆盖好友，且以「界面」为粒度**：好友列表 = 你的**好友**里当前在线的人 + 他们在哪个界面（大厅 `state` 广播），不是全服大厅列表；非好友（比如同房但不是好友的人）不会出现在这里
- **「房间已满」拦不住**：能不能加入只看「在哪个界面 + 有没有房号 + 允不允许加入」，服务端不统计房间里已经站了几个人，所以别人点「加入」时你那边可能已经有一位客人了（一张地图最多 1 位客人，见上面的 1v1 限制）——真要做「房满」得让中继知道房间人数
- **「跟随房主」只跟界面，不跟具体位置**：房主换页面（比如从大地图去皮潜水），访客会被带到同一个页面并自动进同一个房；但页面内的具体进度（海岛、聊天、位置）不跟着，大地图里只保证「进同一间房、站在地图上」
- **观战还是本地状态**：`PresencePanel` 的「观战」只切换本地 `watching` 标记，没有真的把对方画面接过来
- **好友玩到一半换装扮，地图上不会立刻更新**：装扮只在进房时通过 `hello` 同步一次（和对局一致）
- **手机端 UI 不再缩放**：控件是固定像素，小屏手机上会显得偏小（这是「所有设备布局一致」的代价），下限是图标 34px / 按钮 36px

## 打包成 Android APK

前端是纯静态站点，用 **Capacitor** 套一层 Android 壳出包（工程在 `android/`）。

### 一、准备环境（只做一次）

需要 **JDK 21** 与 **Android SDK**。最省事的是装 [Android Studio](https://developer.android.com/studio)：它自带 JDK 21（JBR）与 SDK，装完打开一次让 SDK 初始化完成即可。

> **必须是 JDK 21**：Capacitor 8 的 `capacitor-android` 模块用 Java 21 编译，换成 JDK 17 会直接报
> 「无效的源发行版：21」，JDK 11 更不行。
> 还需要 `android/local.properties` 里写明 `sdk.dir=...`（Android Studio 会自动生成）。

### 二、出包

```powershell
npm run build            # 1) 出 web 产物到 dist/
npx cap sync android     # 2) 同步进 android/app/src/main/assets/public
npx cap open android     # 3) 用 Android Studio 打开工程
```

在 Android Studio 里 `Build → Build Bundle(s) / APK(s) → Build APK(s)`，产物在
`android/app/build/outputs/apk/debug/app-debug.apk`，直接传手机安装即可。

不想开 IDE 也可以命令行出包：

```powershell
cd android
.\gradlew assembleDebug      # 调试包
.\gradlew assembleRelease    # 发布包（需先配签名）
```

### 三、联机服务器（重要）

装成 App 后页面跑在 `https://localhost`，中继地址没法再从同源推导，**必须显式指定**：

```powershell
$env:VITE_RELAY_URL="wss://你的域名/relay"
npm run build
npx cap sync android
```

不设置就是**纯单机包**：点联机入口会提示「当前版本未配置联机服务器」，其余玩法
（单机练习、晋级赛、农场、名人堂、小黄龙联名）全部正常。

### 四、已经替你配好的

| 项 | 值 |
|---|---|
| 包名 / 应用名 | `com.badminton.game` / 「羽毛球」（见 `capacitor.config.ts`） |
| 屏幕方向 | 锁横屏 `sensorLandscape`（`AndroidManifest.xml`） |
| 沉浸式 | `MainActivity.java` 隐藏状态栏与导航栏，边缘滑动可临时唤出 |

### 五、常见问题

- **`npx cap add android` 报 safe-delete 错误**：个别环境会拦截删除操作，导致包名目录或 `build.gradle` 没改完。手动确认 `android/app/build.gradle` 的 `namespace` / `applicationId` 是 `com.badminton.game`，并删掉 `java/` 下残留的 `com/getcapacitor/`。
- **`gradlew` 报找不到 SDK**：在 `android/local.properties` 写一行 `sdk.dir=C\:\\Users\\你\\AppData\\Local\\Android\\Sdk`（Android Studio 通常会自动生成）。
- **`cap sync` 报 safe-delete、assets 没更新**：少数环境会拦截删除操作，导致 web 产物没拷进去（装出来的 APK 还是旧界面）。手动同步一次：把 `dist/` 的内容**覆盖复制**到 `android/app/src/main/assets/public/`，再重新 `gradlew assembleDebug`。
- **联机在 App 里连不上**：直连（WebRTC）依赖 PeerJS 公共信令与 STUN，跨网络常常打不通；稳定做法是配 `VITE_RELAY_URL` 指向自建中继，或按 `src/net/ice.ts` 的说明补一个 TURN 服务器。
- **首屏字体慢**：`index.html` 引了 Google Fonts 的 Outfit / Plus Jakarta Sans，国内网络会等超时再回落到系统字体。想彻底本地化：`npm i @fontsource/outfit @fontsource/plus-jakarta-sans`，在 `main.ts` 里 import 对应 css，再删掉 `index.html` 里的外链。
- **想换图标 / 启动图**：Android Studio 里右键 `android/app/src/main/res` → `New → Image Asset`。
- **WebView 调试**：Chrome 打开 `chrome://inspect`（`capacitor.config.ts` 里已开 `webContentsDebuggingEnabled`，上线前可关掉）。
- **存档位置**：WebView 的 localStorage，卸载 App 会清空。
